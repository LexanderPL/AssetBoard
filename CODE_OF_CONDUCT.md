# Code of Conduct

AssetBoard adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its standards for respectful participation, reporting guidelines, and enforcement guidelines apply
to all project spaces and interactions.

To report behavior that violates the Code of Conduct, contact the maintainers privately through
GitHub's repository contact or private vulnerability reporting channel. Please do not post sensitive
details publicly.
